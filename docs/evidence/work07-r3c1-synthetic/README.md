# WORK-07 R3-C1 — synthetic reconstruction (FAKE model, local archive). NOT evidence about Qwen.

`report.json` is generated by `python -m labs.work07_r3c1.scenarios report.json`, which runs the real `AgentSession`, `PublicBrowser` and pinned `OrchestratorAgent`. Only the model (FAKE, scripted) and the network (`httpx.MockTransport` serving a fictional archive with AX-101 and AX-202) are local.

It contains, for each scenario:
- the per-turn trace: ids, counts and hashes;
- the final state;
- the pages consulted, with fixture URLs only.

It contains no page text, typed queries, conversation messages or credentials.

**Reproducibility:** regeneration is byte-identical **except** `result_sha256` and `view_sha256`. Those are hashes of exactly what the model received, which includes the random per-call untrusted-data frame boundary (a security property, kept on purpose). Tests check that the hashes match the received messages within one run.
