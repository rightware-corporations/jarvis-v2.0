- **Mandatory HANDOFF-FIRST / HANDOFF-LAST (operator decision, 26/11/2026):** Applies to ChatGPT, Claude Code and every agent. Before work, read `docs/HANDOFF.md`, inspect remote HEAD/CI and reconcile concurrent changes.
