Read `docs/BRANCH_STRATEGY.md` for verified consolidation status and exceptions. Do not open a new feature branch for routine engineering without an explicit isolation need and cleanup plan.
- **Mandatory HANDOFF-FIRST / HANDOFF-LAST (operator decision, 26/11/2026):** Applies to ChatGPT, Claude Code and every agent. Before work, read `docs/HANDOFF.md`, inspect remote HEAD/CI and reconcile concurrent changes. After every material work cycle, including a decision, research, test, error, blocker or change without code, append a dated factual checkpoint before reporting the result as persisted.
